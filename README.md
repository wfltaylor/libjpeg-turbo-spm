# libjpeg-turbo for the Swift Package Manager

[libjpeg-turbo](https://github.com/libjpeg-turbo/libjpeg-turbo) built as a Swift Package. Not consistently updated to the latest libjpeg-turbo version.

## Usage

```swift
.package(url: "https://github.com/wfltaylor/libjpeg-turbo-spm", exact: "3.1.1")
```
